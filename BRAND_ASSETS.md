# VlaDDoS Network artwork

The active website preserves the original editorial artwork and compositions in `public/assets/editorial/`: ivory paper, black torn fabric, engraved gold, fuchsia thread and the original character.

- `hero.webp`: the original opening character and gold roulette composition, with live “The other side.” typography.
- `connection.webp`: the physical connection scene; also retained on About.
- `people.webp`: the knot and two-sided relationship composition.
- `exchange.webp`: the engraved V and thread in the original Exchange section and country artwork.
- `contact.webp`: the original character holding the thread on Contact.
- `paper.webp`: the repeating paper substrate.
- `public/assets/vladdos-signature-v2.webp`: the original signature used as the header's mask, with the NETWORK caption in HTML.
- `public/favicon.svg`: the gold V monogram with the fuchsia thread on black, matching the editorial V-and-thread motif. `public/icons/thread.svg` keeps the former icon URL compatible.
- `public/favicon.ico`, `public/icons/vladdos-network-{16,32}.png` and `public/apple-touch-icon.png`: raster exports of the same native SVG for small browser icons and saved shortcuts. The HTML uses a versioned favicon URL to refresh the former circular icon.

Text, controls and forms remain live HTML. New content is integrated into the original page structures; no replacement hero, new generated imagery, invented clients or implied commercial coverage are introduced. Other historical identity assets remain in `research/legacy-assets`. Historical notes record provenance, not current business claims.

See `research/NETWORK_DESIGN_SYSTEM.md` for current typography, materials and interactions. Original asset preparation is recorded in `research/VLADDOS_EDITORIAL_DESIGN.md`.

The homepage connection scene uses the original braid texture on separate, constrained strand geometry. `connection-clean-v2.webp` supplies an ImageGen-edited clean plate only inside the narrow removal mask under the old cord; the surrounding composition comes from the unchanged original. The cord has bending stiffness, contact shadows and mouse dragging. The spool stays fixed and the circular endpoint links to the selected intake path. Reduced motion and unavailable graphics retain the source image. See `research/THREAD_MOTION.md` for the exact edit prompt, implementation and verification.
